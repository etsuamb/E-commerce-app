# E-Commerce Mobile App

A mobile e-commerce application focused on a simple shopping experience, from browsing products to checkout and order history.

## Features

- User registration and login
- Product browsing and category-based discovery
- Product filtering
- Shopping cart
- Checkout flow
- Order history
- Product management for sellers
